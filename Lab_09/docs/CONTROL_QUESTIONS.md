# Контрольні запитання до Лабораторної роботи №9

### 1. Чим concurrency відрізняється від parallelism?
* **Concurrency** — це організація коду для одночасної обробки кількох задач за допомогою перемикання контексту (наприклад, під час очікування I/O).
* **Parallelism** — це фізично одночасне виконання обчислень на декількох ядрах процесора.

### 2. Що таке GIL та яку роль він відіграє у CPython?
**GIL (Global Interpreter Lock)** — це механізм у CPython, який гарантує, що лише один потік виконує байткод Python у межах одного процесу. Це блокує справжній паралелізм для CPU-bound задач через `threading`.

### 3. Коли доцільно використовувати `ThreadPoolExecutor`, а коли `ProcessPoolExecutor`?
* `ThreadPoolExecutor` використовується для **I/O-bound** задач (мережеві запити, читання/запис файлів), коли потоки більшу частину часу очікують.
* `ProcessPoolExecutor` використовується для **CPU-bound** задач (важкі обчислення, векторизація), оскільки кожен процес отримує власний інтерпретатор і bypass-ить GIL.

### 4. Як обчислюється Speedup?
$$\text{Speedup} = \frac{T_{\text{baseline}}}{T_{\text{optimized}}}$$
Якщо значення менше 1.0, це означає уповільнення через накладні витрати (overhead).
