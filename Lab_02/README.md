## Опис проєкту

Проєкт є модульним консольним застосунком для аналізу успішності студентів. Метою є демонстрація навичок професійного використання базових (list, tuple, set, dict) та розширених (collections) структур даних Python, функціональної декомпозиції, замикань (closures) та декораторів.

## Реалізований функціонал (згідно з вимогами)

- **Базові структури:**
  - `list`: Зберігання загального масиву записів студентів.
  - `tuple`: Незмінне зберігання списку оцінок кожного студента `(95, 92, 88)`.
  - `set`: Отримання множини унікальних дисциплін.
  - `dict`: Створення індексу для швидкого доступу до записів за `id`.
- **Модуль `collections`:** 
  - Використання `Counter` для підрахунку студентів за дисциплінами.
  - Використання `defaultdict` для зручного групування записів.
- **Генератори та Comprehensions:** Використано List, Set та Dict comprehensions для оптимізації обробки даних.
- **Функціональна декомпозиція:** Логіку розділено на незалежні модулі (`data.py`, `processors.py`, `analytics.py`, `decorators.py`).
- **Просунуті можливості Python:**
  - `*args` та `**kwargs` для гнучкого передавання аргументів.
  - `lambda` функції для визначення критеріїв сортування.
  - `closure` (замикання) для створення гнучкої функції-фільтра за заданим середнім балом.
  - `decorator` (`@measure_time`) для вимірювання часу виконання функцій та бенчмаркінгу.
- **Алгоритмічні операції:** Пошук (O(1) та O(n)), фільтрація, сортування (O(n log n)), групування та агрегація (середній бал, мінімум/максимум).
