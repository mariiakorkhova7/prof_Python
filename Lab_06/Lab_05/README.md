# Grading Importer (Лабораторна 5 - Варіант 7)

Модуль для надійного імпорту та експорту системи оцінювання студентів. 
Підтримує перевірку даних, толерантний/строгий режими, потокове читання та атомарний експорт.

## Запуск
1. Встановіть залежності: `pip install -e .` (або просто `pip install pyyaml`)
2. Запустіть програму: `python -m grading_importer.main`
